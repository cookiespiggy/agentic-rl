# 02. 数据流图

> 端到端数据流：8 条人造数据 → SFT 模型 → GRPO 模型 → 评估
>
> 看懂这个图就懂 Agentic RL 最小示例的全貌。

## 完整数据流

```
┌─────────────────────────────────────────────────────────────────┐
│  1. 人造数据 (data/make_data.py)                                │
│     ChatML messages 格式                                        │
│     ┌──────────────────────────────────────────────────┐        │
│     │ system: "你是情感分类助手. 只能从 {正面,负面,中性} │        │
│     │          中三选一, 严格只输出一个词."               │        │
│     │ user:   "请判断情感倾向: 吃起来口感不错..."         │        │
│     │ assistant: "正面"                                  │        │
│     └──────────────────────────────────────────────────┘        │
│                          ↓                                      │
│     sft_train.jsonl (8 条) + sft_test.jsonl (3 条)              │
└─────────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────────┐
│  2. SFT 训练 (sft/train_sft.py)                                 │
│     trl.SFTTrainer + ChatML messages                            │
│     起点: Qwen2.5-0.5B (FP32, MPS)                              │
│     超参: epochs=3, batch=1, lr=5e-5, max_len=512                │
│     损失: assistant-only (trl 默认)                              │
│                          ↓                                      │
│     24 步, 27.6 秒                                              │
│     loss: 5.52 → 0.36                                           │
│                          ↓                                      │
│     sft_output/ (1.9 GB safetensors)                            │
└─────────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────────┐
│  3. GRPO 训练 (rl/train_grpo.py)                                │
│     trl.GRPOTrainer + reward_func                               │
│     起点: sft_output/ (FP32, MPS)                               │
│     超参: max_steps=20, batch=1, lr=1e-6, G=4, beta=0.01        │
│     奖励: 命中 1.0 / 不命中 0.0                                 │
│                          ↓                                      │
│     ┌─ 每 step ──────────────────────────────────┐               │
│     │ 1) 取 1 个 prompt                           │               │
│     │ 2) 模型生成 G=4 个 completion (16 tokens)   │               │
│     │ 3) reward_func 算 4 个 reward               │               │
│     │ 4) 组内 advantage = (r - mean) / std        │               │
│     │ 5) 更新模型参数                             │               │
│     └─────────────────────────────────────────────┘              │
│                          ↓                                      │
│     20 步, 27.3 秒                                              │
│     rewards/mean: 0.25 / 0.25 / 1.0 / 0 / 1.0                   │
│                          ↓                                      │
│     grpo_output/ (1.9 GB safetensors)                           │
└─────────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────────┐
│  4. 评估 (eval/evaluate.py)                                     │
│     加载任意模型 + 测试集 (3 条)                                 │
│                          ↓                                      │
│     对每条 prompt:                                               │
│       - 模型生成 (max_new_tokens=8)                             │
│       - 提取第一个 {正面, 负面, 中性}                            │
│       - 跟 ground truth 对比                                    │
│                          ↓                                      │
│     打印准确率 + 各类别命中数                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 关键数据形态

### 1. 训练数据（jsonl 每行）

```json
{
  "messages": [
    {"role": "system", "content": "你是情感分类助手..."},
    {"role": "user", "content": "请判断情感倾向: ..."},
    {"role": "assistant", "content": "正面"}
  ]
}
```

### 2. SFT 后模型输入

SFT 训练时，trl 用 Qwen 的 chat template 把 messages 拼成单个 string：
```
<|im_start|>system
你是情感分类助手...<|im_end|>
<|im_start|>user
请判断情感倾向: 吃起来口感不错...<|im_end|>
<|im_start|>assistant
正面<|im_end|>
```

**labels 掩码**：只有 `assistant` 部分的 token 算 loss（`mean_token_accuracy: 0.977` 在 SFT 24 步末）。

### 3. GRPO 数据集（结构化后）

```json
{
  "prompt": [
    {"role": "system", "content": "你是情感分类助手..."},
    {"role": "user", "content": "请判断情感倾向: ..."}
  ],
  "answer": "正面"
}
```

- `prompt`: 喂给模型（去掉 assistant，模型自己生成）
- `answer`: 喂给 reward_func 当 ground truth（不进模型）

### 4. GRPO 训练内部

每 step：
```
prompt: [system, user]
  ↓
模型生成 4 个 completion:
  - completion_1: [{role:assistant, content: "正面"}]  → reward 1.0
  - completion_2: [{role:assistant, content: "负面"}]  → reward 0.0
  - completion_3: [{role:assistant, content: "正面"}]  → reward 1.0
  - completion_4: [{role:assistant, content: "中性"}]  → reward 0.0
  ↓
rewards: [1.0, 0.0, 1.0, 0.0]
mean: 0.5, std: 0.577
advantages: [+0.87, -0.87, +0.87, -0.87]
  ↓
Policy gradient: completion_1 和 3 被强化, 2 和 4 被弱化
```

## 评估的"对/错"判断逻辑

```python
def extract_label(generated: str) -> str | None:
    for label in ["正面", "负面", "中性"]:
        if label in generated:
            return label
    return None
```

**示例**：
- 模型生成 "负面\n请判断..." → `extract_label` 返回 "负面"（第一个匹配）
- 模型生成 "正面\nassistant\n正面" → 仍然返回 "正面"（第一个匹配）
- 模型生成 "我觉得不错"（无标签）→ 返回 None，判错

**这是宽容的提取**（"包含"即可），不严格要求"只输出一个词"。但因为 system prompt 约束了"严格只输出一个词"，8 tokens 限制下模型大致会遵守。
